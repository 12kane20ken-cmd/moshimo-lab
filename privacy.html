プライバシーポリシー

制定日：2026年10月24日

トップ利用規約

このポリシーは、チャンネル「もしもの実験室」の運営者が使用するアプリ「shorts-automation」（以下「本アプリ」）が、 Google アカウントおよび YouTube のデータをどのように扱うかを定めます。

1. YouTube API サービスの利用

本アプリは YouTube API サービスを使用しています。本アプリを利用することで、 YouTube 利用規約に同意したものとみなされます。 Google によるデータの取り扱いについては Google プライバシーポリシーをご覧ください。

2. 利用者

本アプリは運営者本人の Google アカウントでのみ使用します。動画の視聴者や第三者の Google アカウントへのアクセスは行いません。

3. 取得する情報と目的

  • 動画のアップロード（youtube.upload）：制作した動画とタイトル・説明文を運営者のチャンネルに投稿するため
  • チャンネルと動画の情報の読み取り（youtube.readonly）：投稿した動画の状態と再生数・高評価数・コメント数を確認するため
  • YouTube アナリティクスの読み取り（yt-analytics.readonly）：運営者の動画の視聴時間などを集計し、次の企画づくりに使うため
  • 公開動画の検索（API キー）：YouTube 上で公開されている動画のタイトル・再生数・投稿日を、話題の傾向を調べるために取得します

取得した情報は上記の目的にのみ使用し、販売・広告利用・第三者への提供は行いません。

4. 保存場所と保存期間

  • Google が発行する認証情報（リフレッシュトークン等）は、暗号化された GitHub Actions のシークレットにのみ保存します。
  • 集計した数値は、運営者の非公開の GitHub リポジトリに保存します。
  • 話題の傾向の調査結果は直近 30 日分だけを保存し、それより古いものは自動で削除します。

5. アクセス許可の取り消し

本アプリへのアクセス許可は、Google アカウントの サードパーティ製のアプリとサービス（セキュリティ設定）からいつでも取り消せます。 取り消すと、本アプリは以後データにアクセスできません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

7. 変更

このポリシーを変更する場合は、このページで公開します。
